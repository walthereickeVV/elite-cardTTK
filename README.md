# elite-cardTTK
# 🏗️ PROFSTROY ELITE — Премиальная сайт-визитка строительного рекрутинга

> **Версия:** 1.0 | **Стиль:** Индастриал-люкс | **Год:** 2026

Современная, интерактивная сайт-визитка, которая заменяет бумажную визитку и одновременно работает как мини-лендинг для привлечения строителей. Золотые акценты, строительная сетка на фоне, переключатель вакансий и динамический QR-код.

---

## 🔥 Уникальные особенности

| № | Фича | Описание |
|---|------|----------|
| 1 | **Анимированная строительная сетка** | Фоновая сетка двигается, создавая ощущение стройплощадки |
| 2 | **Плавающие инструменты** | 🏗️ 🔨 🧱 парят по углам экрана (CSS-анимация) |
| 3 | **Золотая полоса сверху** | Премиальный акцент, визуальная иерархия |
| 4 | **Интерактивный переключатель вакансий** | 4 профессии: меняется иконка, зарплата, описание и QR-текст |
| 5 | **Динамический QR-код** | Меняется в зависимости от выбранной профессии |
| 6 | **Анимированный счётчик** | Показывает, сколько человек уже трудоустроено (набегает от 0 до 1250) |
| 7 | **Две колонки** | Контакты + вакансии слева, зарплаты + статистика + QR справа |
| 8 | **Стеклянный эффект (glassmorphism)** | Blur-фон, золотые границы |
| 9 | **Полностью адаптивен** | На телефоне колонки складываются в одну |
| 10 | **Все контакты кликабельны** | Прямые ссылки на WhatsApp и Telegram |
